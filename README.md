## 🔍 Overview

GarudaAI (formerly GarudaAI) is an AI-powered Insider Threat Detection platform that ingests and analyzes millions of behavioral events from the **CERT Insider Threat Dataset R4.2** — the gold standard academic dataset from Carnegie Mellon University's Software Engineering Institute.

The platform provides:

- **Real-time behavioral trust scoring** — Every employee has a dynamic trust score (0–100) computed from logon patterns, data access, email activity, USB usage, and after-hours behavior.
- **AI-powered incident investigation** — Suspicious employees trigger automated Google Gemini AI investigation reports with evidence summaries, risk factors, and recommended actions.
- **Just-In-Time (JIT) Privileged Access Management** — Temporary, scoped access tokens issued on-demand and auto-revoked after use.
- **Role-Based Access Control (RBAC)** — Analyst, Manager, and Admin roles with granular permission enforcement.
- **Post-Quantum Cryptography (PQC)** — Kyber-1024 key encapsulation for future-proof data encryption.
- **Identity Monitoring** — Anomaly detection on user identity telemetry (geo, device, behavioral drift).

## 🚀 Installation

### Prerequisites

- Python 3.10 or higher
- Node.js 18+ and npm
- MongoDB (local or MongoDB Atlas)
- A [Google Gemini API key](https://aistudio.google.com/app/apikey)

### 1. Clone the Repository

```bash
git clone https://github.com/buildwithneel/Insider-threat-detection.git
cd Insider-threat-detection
```

### 2. Set Up Environment Variables

```bash
cp .env.example .env
```

Edit `.env` and fill in your real values (MongoDB URI, Gemini API keys, etc.).

### 3. Set Up the Backend

```bash
# Create a virtual environment
python -m venv venv

# Activate it (Windows)
venv\Scripts\activate

# Activate it (macOS/Linux)
source venv/bin/activate

# Install dependencies
pip install -r backend/requirements.txt
```

### 4. Set Up the Frontend

```bash
cd frontend
npm install
cd ..
```

## 📂 Dataset Setup

> [!IMPORTANT]
> **The dataset is NOT included in this repository** because it is publicly available on Kaggle and exceeds GitHub size limits.

### Step 1 — Download from Kaggle

🔗 **[Download CERT Insider Threat Dataset](https://www.kaggle.com/datasets/mrwellsdavid/insider-threat-detection)**

### Step 2 — Place Raw Files

Extract the downloaded archive and copy the required CSV files directly into the `dataset/` directory:

```
dataset/
    logon.csv
    device.csv
    email.csv
    file.csv
    http.csv
    psychometric.csv
    answers.csv
```

Once you have placed the files in the `dataset/` directory, the project is fully functional and ready to run.

## 🔑 Environment Variables

Copy `.env.example` to `.env` and configure:

```env
PORT=5000
FLASK_ENV=development
DEV_MODE=true
MONGODB_URI=mongodb://localhost:27017/garudaai

# Get your key from: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=your-gemini-api-key-here
```

See [`.env.example`](.env.example) for the full list of variables.

## ▶️ Running the Platform

### Backend (Flask API)

```bash
# From project root with virtual environment activated
python backend/app.py
```

The API will start at `http://localhost:5000`

### Frontend (React)

```bash
cd frontend
npm run dev
```

The dashboard will open at `http://localhost:5173`

### Quick Start (Windows)

```bash
start_platform.bat
```

## 📡 API Documentation

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/employees` | Get all employee risk profiles |
| `GET` | `/api/employees/:id/trust-score` | Get employee trust score history |
| `GET` | `/api/employees/:id/timeline` | Get behavioral event timeline |
| `POST` | `/api/investigate/:id` | Trigger AI investigation report |
| `POST` | `/api/jit/request` | Request JIT privileged access token |
| `DELETE` | `/api/jit/revoke/:token` | Revoke a JIT access token |
| `GET` | `/api/alerts` | Get active threat alerts |
| `POST` | `/api/auth/login` | Authenticate user |
| `GET` | `/api/rbac/roles` | Get RBAC role definitions |

Full API documentation: [`docs/API_DOCUMENTATION.md`](docs/API_DOCUMENTATION.md)
