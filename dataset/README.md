# 📂 Dataset — CERT Insider Threat Dataset R4.2

> **⚠️ The dataset is NOT included in this repository.**
>
> It is publicly available on Kaggle and exceeds GitHub's file size limits.
> You must download it yourself and place the files in this folder.

---

## 📥 Download Instructions

### Step 1 — Download from Kaggle

Visit the Kaggle dataset page and download the files:

🔗 **[CERT Insider Threat Dataset — Kaggle](https://www.kaggle.com/datasets/mrwellsdavid/insider-threat-detection)**

You will need a free Kaggle account to download.

### Step 2 — Place Raw Files

Extract the downloaded archive and copy all files into `dataset/kaggle_raw/`:

```
dataset/
└── kaggle_raw/
    ├── logon.csv
    ├── device.csv
    ├── email.csv
    ├── file.csv
    ├── http.csv
    ├── psychometric.csv
    ├── answers.csv
    └── LDAP/
        ├── 2009-12.csv
        └── ... (monthly snapshots)
```

### Step 3 — Convert to SentinelAI Format

Run the conversion script from the **project root**:

```bash
python scripts/convert_kaggle_cert.py \
  --source dataset/kaggle_raw \
  --output dataset
```

This generates the processed CSV files that SentinelAI reads.

### Step 4 — Import into MongoDB

```bash
python scripts/import_data.py
```
