## [1.0.0] — 2025-08-03

### 🎉 Initial Open Source Release

This is the first public release of the SentinelAI Insider Threat Detection Platform — an enterprise-grade AI-powered platform for detecting, analyzing, and mitigating insider threats using the CERT Insider Threat Dataset R4.2.

---

### ✅ Added

#### Core Platform
- **Trust Score Engine** — Real-time behavioral trust scoring (0–100) for every monitored employee based on:
  - Logon/logoff patterns and after-hours activity
  - Data exfiltration indicators (USB, email attachments, cloud uploads)
  - HTTP web activity anomaly detection
  - File access pattern analysis
  - Psychometric behavioral baselines
- **Employee Risk Dashboard** — React-based live dashboard with threat heat maps, trend charts, and risk distribution analytics

#### AI Investigation Engine
- **Gemini AI Integration** — Automated incident investigation reports generated by Google Gemini AI models
- **Multi-Key AI Gateway** — Load-balanced Gemini API key pool for high availability and quota management
- **AI Assistant** — Contextual employee investigation with evidence summary, risk factors, and recommended remediation

#### Access Control
- **Just-In-Time (JIT) Privileged Access Management** — Time-limited, scoped access tokens with automatic expiry and audit logging
- **Role-Based Access Control (RBAC)** — Admin, Manager, and Analyst roles with granular permission sets
- **JWT Authentication** — Stateless token-based authentication with bcrypt password hashing

#### Security
- **Post-Quantum Cryptography (PQC)** — Kyber-1024 key encapsulation (NIST FIPS 203 standard) for future-proof encryption
- **Identity Monitoring** — Anomaly detection on user identity telemetry including geolocation, device fingerprint, and behavioral drift
- **API Rate Limiting** — Per-IP request rate limiting to prevent abuse

#### Data Pipeline
- **CERT Dataset Converter** (`scripts/convert_kaggle_cert.py`) — Converts raw Kaggle CERT R4.2 CSV files to GarudaAI/SentinelAI format
- **MongoDB Importer** (`scripts/import_data.py`) — Bulk import pipeline with proper indexing
- **Synthetic Data Generator** — For development and testing without real dataset
- **Identity Dataset Generator** — Human-machine identity telemetry simulation

#### Documentation
- Comprehensive `README.md` with setup instructions, architecture, and API reference
- `dataset/README.md` with step-by-step Kaggle download and setup guide
- Full API documentation (`docs/API_DOCUMENTATION.md`)

- Scoring engine specification (`docs/SCORING_ENGINE.md`)

#### Tests

### ⚠️ Known Limitations (v1.0.0)

- LDAP/Active Directory sync not yet implemented
